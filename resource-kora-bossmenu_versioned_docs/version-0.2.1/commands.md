# Commands

Kora Bossmenu registers no chat or console commands. A search of `client/` and `server/` finds no `RegisterCommand` and no Kora Core `addCommand` call.

Menus are opened through the target points, the `openBossMenu` / `openApplication` [client exports](./api/client-exports.md) or the legacy [client events](./api/events.md). See [How to use](./how-to-use.md) and the [Management menu](./management-menu.md).
